# Dynamic Product Dashboard

## Project Description
A dynamic React e-commerce product dashboard that displays a list of products with their name, price, and availability status. Users can filter products by availability (All, In Stock, Out of Stock), and out-of-stock items are visually distinguished using CSS Modules and Material UI components.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Navigate into the project directory:
   ```bash
   cd product-dashboard
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```

## Running Tests
To run the automated Jest and React Testing Library test suite:
```bash
npm test
```
